# TAP Academy UI Clone — Project 05

A responsive, frontend-only learning platform landing page inspired by the visual language of TAP Academy. This is an independent educational practice project and is **not** the official TAP Academy website.

## Features
- Responsive desktop, tablet, and mobile layout
- Sticky navigation with mobile menu
- Hero section, course cards, learning journey, benefits, testimonials-style content, and CTA
- Smooth section navigation and active section link styling
- YouTube tutorial search links for Java Full Stack, Web Development, and DSA courses
- Built with semantic HTML, CSS, and vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## Deploy with GitHub Pages
1. Create a GitHub repository named `tap-academy-clone`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the published URL and add it to the repository description.
